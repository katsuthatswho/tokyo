# Tokyo

A mobile Tokyo food guide based on 36 places from the original food list. Includes neighbourhood maps, food-type browsing, Millie’s ratings, personal ratings, saved places, a daily plan and visited tracking.

## GitHub Pages

Publish from the `main` branch and `/(root)` folder in Settings → Pages. No build step or server is required.

The guide and its source food list are public on GitHub Pages. Personal ratings, notes and visits are stored only in the visitor’s browser.

## Moving your personal data

On the previous site, open Settings and download a backup. On the GitHub Pages site, open Settings and restore that backup. Browser storage is separate for each site address.

## Data and maps

The 36 food places retain the spreadsheet’s ratings, notes and links. Area markers show approximate neighbourhood centres, not exact restaurant locations. Map tiles and attribution use OpenStreetMap.
